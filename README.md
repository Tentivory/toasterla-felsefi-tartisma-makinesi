# Toaster'la Felsefi Tartışma Makinesi

## Bu Nedir?

Bu, insanlık tarihinin en ciddi ve en anlamsız felsefi tartışma cihazıdır. 
Bir toaster (ekmek kızartma makinesi) ile hayatın anlamı, özgür irade, 
ve ekmek dilimlerinin ontolojik durumunu tartışabilirsiniz.

**Önemli Uyarı:** Toaster her zaman haklıdır. İtiraz etmeyin. İtiraz ederseniz kızarırsınız.

## Nasıl Çalışır?

1. Python 3 kurulu olsun (yoksa toaster sizi yargılar).
2. `python toaster_felsefe.py` çalıştırın.
3. Sorunuzu yazın.
4. Toaster düşünsün.
5. Kaybedin.

## Özellikler

- Gerçekten çalışır.
- Sonsuz döngü (hayat gibi).
- Rastgele cevaplar (felsefe gibi).
- KeyboardInterrupt ile çıkış (kaçış gibi).
- Gizli mesajlar (demokrasi gibi, ama saklı).
